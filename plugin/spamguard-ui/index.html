SpamGuard

Spam protection for this repeater. SpamGuard has its own page, where you can see what it has caught and change how it works.

Open SpamGuard

The page is on port 8091 of this machine. Before it can protect anything, paste an openHop API token into SpamGuard's settings here in System > Plugins (api_key), then restart the plugin.

If openHop runs in Docker, port 8091 also needs publishing on openHop's container.
