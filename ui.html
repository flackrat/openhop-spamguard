        Exceptions

        Things SpamGuard should leave alone.

        Trusted senders

        Never counted as spam names and never de-duplicated. Channel names are not verified, so a spammer can copy a trusted name. SpamGuard still blocks a campaign even if one of its names is trusted, and logs a warning when a trusted name turns up somewhere new.

        Repeaters never blocked automatically

        Covers every hash width, so 27 also covers 27AB. You can still block these by hand.

        Text never blocked

        Messages containing any of these (capitals ignored) are never de-duplicated or treated as campaigns. Use for bots, net check-ins or regular announcements.

        Channels SpamGuard can read

        Spam on channels SpamGuard can't read is not detected. Hashtag channels only need the name.

        Not re-blocked

        Blocks you removed by hand. SpamGuard won't re-create these for 24 hours.

        Evidence log

        A day-by-day record of every channel message SpamGuard reads, its spam signals, whether it was caught, and your “This is spam” / “Not spam” answers. Download it to review what happened, or to have SpamGuard's detection tuned against real traffic with the replay tool.

        Scrambled downloads replace every sender name (and @mentions of them) with a code, keeping each name's spam score and shape (e.g. AA9AAAAA), so the file can be shared without revealing who said what. Message text is kept.

            What's new

            How SpamGuard works

            SpamGuard reads the channel messages your repeater hears and looks for the signs of a spammer: made-up names that change every message, lots of brand-new names arriving through one repeater, and the same message sent under different names.

            When it finds spam it adds a rule to openHop so your repeater stops passing it on. It never changes your own openHop rules, and every automatic block ends by itself once the spam stops.

            Getting started

            Leave SpamGuard on Monitor for a day. Messages it would have stopped are marked “Would be stopped”. If it is only catching spam, switch to Protect.

            If it blocks someone genuine

            Press Not spam on their message. Their name is trusted from then on, and if a text block caught them, that block is removed. If a whole repeater was blocked, remove that block above. Busy events and people repeating the same long message are the usual causes. Relaxed sensitivity makes both less likely.

            Limits

            SpamGuard only controls what your repeater forwards. People in direct range of the spammer will still hear him, so the more repeaters near the source run a filter, the better. It cannot read private channels or direct messages unless you give it the channel key.
